How to use this site

This catalogue is a teaching sandbox for a data-science class. You are expected to collect the data with a scraper you wrote and can explain. Using an AI assistant to help you write, debug or review that code is fine and encouraged. Asking an assistant to read the site and hand you the answers is not the exercise.

Whatever you conclude, you should be able to say where the number came from, what you removed from the data and why, and what the data cannot tell you.

Catalogue data derived from the UCI Online Retail II dataset (Chen, D., 2019). Fictional storefront for teaching purposes.
